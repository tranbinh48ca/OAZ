Framework được xây dựng dựa trên tài liệu vận hành thực tế của Trần Văn Bình (MobiFone ~200 DB, 1200+ servers), tài liệu chính hãng Oracle, và best practices ngành. Ba cấp độ thành thạo, áp dụng cho mọi DBA.

Foundation (F)

Chuyên gia, kiến trúc hệ thống lớn, xử lý sự cố phức tạp, mentor team. 5+ năm kinh nghiệm.

SQL — Daily Health Check (Phụ lục I)
-- 1. Kiểm tra active session & blocking
SELECT s.sid, s.serial#, s.username, s.status,
       s.wait_class, s.event, s.seconds_in_wait,
       s.blocking_session, s.sql_id
FROM v$session s
WHERE s.type = 'USER'
  AND s.status IN ('ACTIVE','KILLED')
ORDER BY s.seconds_in_wait DESC;

-- 2. Kiểm tra tablespace usage
SELECT tablespace_name,
       ROUND(used_space/1024,2) used_gb,
       ROUND(tablespace_size/1024,2) total_gb,
       ROUND(used_percent,1) pct_used
FROM dba_tablespace_usage_metrics
ORDER BY pct_used DESC;

-- 3. Kiểm tra invalid objects
SELECT owner, object_type, object_name, status
FROM dba_objects
WHERE status = 'INVALID'
  AND owner NOT IN ('SYS','SYSTEM')
ORDER BY owner, object_type;
